# Ocean Tic Tac Toe – Frontend

Modern, minimalistic Tic Tac Toe built with React 18 following the "Ocean Professional" theme.

Features:
- Interactive 3x3 board
- Single player (vs. computer) and Two player modes
- Status and result display (win/draw)
- Start and Reset controls
- Centered layout with player info above and controls below

Scripts:
- npm start — start dev server
- npm run build — production build
- npm test — run tests (none added by default)

Tech:
- React 18
- react-scripts 5
- CSS (no heavy UI frameworks)

Theme:
- Primary: #2563EB
- Secondary: #F59E0B
- Background: #f9fafb
- Surface: #ffffff
- Text: #111827
